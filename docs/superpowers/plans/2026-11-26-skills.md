# Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Twelve skills (1–100) that earn XP from doing things and give perks, boosted by the existing jewelry, shown on a K screen with an XP popup.

**Architecture:** A common `com.mechanical.skills` package: `Skill` enum, `Skills` (XP curve, attachment, `addXp`, effective level, perk rolls), `SkillHooks` (XP from existing hooks), `SkillPerks` (perk effects), and a jewelry boost in `Jewelry`. Client code in `com.mechanical.client.skills`: the K screen and the popup.

**Tech Stack:** NeoForge 26.3.0.95, MC 26.3, Java; attachments with owner-only `.sync`, `CustomPacketPayload`, GameTest (`TestArea.of`), `client/ui/HideUi`, `client/ui/GuiShots`.

**Spec:** `docs/superpowers/specs/2026-11-26-skills-design.md`

## Global Constraints

- Worktree `C:/Users/Yngve/Documents/mm_wt/skills`, branch `feat/skills`. Stage files by name. Never touch the main checkout.
- XP curve: total XP for level L = `25·(L−1)² + 75·(L−1)`, level 1..100. XP beyond level 100 is kept but the level stays 100.
- Effective level = own level + jewelry bonus, capped at 120. Perks use the effective level.
- XP amounts, perks, the gem→skill table and the jewelry bonuses (gold +3, electrum +2, silver +1, flawless ×2): exactly as in the spec tables.
- All random perk rolls on the server, with the level's own `RandomSource`.
- Attachment syncs only to its owner: `.sync((holder, to) -> holder == to, codec)` (as `viewer/SeenItems`).
- Common code never references client classes. Gametests: `./gradlew runGameTestServer --no-configuration-cache` (long timeout; once or twice per task). Test pattern: `com.mechanical.viewer.ViewerTest`.
- Style: `client/ui/HideUi`, look like `client/quests/QuestScreen` and `client/viewer/RecipeViewScreen`.
- Lang in `assets/mechanical/lang/en_us.json`. Commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Version at the end: `mod_version` 0.223.0 → **0.224.0**.

## Review Focus

1. A level-up that skips several levels in one `addXp` (big XP): one popup naming the final level, no crash. (Task 1 test `multiLevel`.)
2. XP awarded on the client side by a hook that runs on both sides: must be ignored, not doubled. (Task 2: every hook checks `ServerPlayer`.)
3. A perk that gives extra drops must never duplicate items that do not stack (tools, damaged items). (Task 3 test `noDupeUnstackable`.)
4. Jewelry bonus when the same gem is worn twice: stacks (two rings) — and a ring removed drops the effective level at once. (Task 4 test.)
5. A player who joins an old world: no skills attachment → all level 1, no error. (Task 1 test `freshPlayer`.)
